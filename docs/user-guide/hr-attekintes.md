## Mire való

A HR modul a **céges tagságok** (dolgozók), a **naptár** (logisztikai feladatok + roster műszakok + távollét) és a **szabadság keretek** kezelése.

## Hol találod

**Oldalsáv → HR**

| Menüpont | Útvonal |
|----------|---------|
| Áttekintés | `/hr` |
| Dolgozók | `/hr/people` |
| Naptár | `/hr/calendar` |
| Szabadság | `/hr/leave` |
| Szabadság összesítő | `/hr/leave-summary` |
| Órák | `/hr/hours` |
| Cégek | `/hr/companies` |

Saját naptár és feladatok: **Általános → Saját feladataim** (`/hr/me`) — ehhez elég a dolgozó profil, HR jog nem kell.

## Két beosztás mód

- **Logisztika** — a naptárban a szállítási feladatok jelennek meg; munkaidőt a Logisztika modulban állítod.
- **Roster** — HR kézzel vesz fel műszakokat a naptárban.
