## Mire való

Központi képtár és fájltár: termékképek, összeszerelési útmutató fájlok, duplikáció-mentes feltöltés.

## Hol találod

- **Termék / összeszerelés szerkesztés** → **Médiatár** gomb
- **Adminisztráció → Médiatár** (`/admin/media`) — teljes kezelőfelület

## Szükséges jogosultság

- Böngészés: `media:read` vagy `inventory:read`
- Feltöltés / link: `media:upload` vagy `inventory:write`
- Törlés a könyvtárból: `media:delete`

## Lépésről lépésre

1. Szerkesztés közben kattints **Médiatár**.
2. **Galéria** — keresés meglévő média között.
3. **Feltöltés** — fájl kiválasztása (duplikátum hash alapján újrahasznosítás).
4. **Link hozzáadása** — külső URL regisztrálása képként.
5. Jelöld ki a kívánt elemeket, állítsd a sorrendet, majd **Alkalmazás**.
