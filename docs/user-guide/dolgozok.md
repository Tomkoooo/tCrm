## Mire való

Egy **dolgozó sor = egy cég tagsága**. Ugyanaz a CRM fiók több cégben is megjelenhet külön sorokban.

## Hol találod

**Oldalsáv → HR → Dolgozók** (`/hr/people`)

## Új dolgozó

1. **Új dolgozó** → válaszd a **Cég**et.
2. Állítsd a **Beosztás mód**ot: Logisztika vagy Roster.
3. Opcionálisan e-mail, telefon, CRM fiók.

## Más céghez

A profilon **Hozzáadás céghez** létrehoz egy új tagságot (ugyanaz a név / fiók).
