## Mire való

Raktárak (pl. Kispest, Erzsébet, Récsei) kulcsainak és meta adatainak kezelése; raktárhoz rendelt felhasználók a logisztikai szállításoknál.

## Hol találod

**Adminisztráció → Raktárak** (`/admin/warehouses`)

## Szükséges jogosultság

- Lista / megtekintés: `warehouses:read`
- Szerkesztés: `warehouses:manage`

## Lépésről lépésre

1. Nyisd meg a **Raktárak** listát.
2. Válassz raktárat vagy hozz létre újat (`warehouses:manage`).
3. Szerkesztésnél állítsd be a **hozzárendelt felhasználókat** — ők kapják az értesítéseket és javasolt csapatot új szállításnál.
4. A raktár **kulcs** egyezik az Excel `warehouse 1./2./3.` oszlopokkal.
